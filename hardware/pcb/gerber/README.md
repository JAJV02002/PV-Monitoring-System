# PCB manufacturing files

[Gerber_PCB_EMON.zip](Gerber_PCB_EMON.zip) contains the supplied copper, silkscreen, solder-mask, solder-paste and board-outline layers, together with plated and non-plated drill files and the Gerber job file.

The job file identifies KiCad 8.0.4 and an export date of October 23, 2024. It specifies two copper layers, a 1.6 mm board thickness and a size of approximately 100.4 × 70.4 mm.

The manufacturing files are preserved byte-for-byte inside the archive; macOS metadata and the outer folder were removed. They were not regenerated from the current KiCad files. Review the intended board revision and fabrication settings before ordering.
