# PCB assembly model

[tarjeta_SolarVista_STEP.zip](tarjeta_SolarVista_STEP.zip) contains the original `tarjeta_SolarVista.step` assembly export from the PCB project. It is compressed for download and preserves the original STEP data.

Extract the archive and open the STEP file in a compatible CAD viewer to inspect the PCB assembly alongside the [enclosure meshes](../../cad/README.md).
